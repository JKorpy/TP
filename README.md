### Project Overview
BVIPs (Best Value Indicator Product Selector) is a full-stack web application designed to help users compare prices of products across multiple Irish stores (E.g. Centra, Mace, Spar). The platform allows users to find the best value of items by building a shopping list and identifying the most cost-effective store, saving time and money for individuals and families. Our team has successfully implemented many key features including Login/Register, Generic Navigation, Filter/Search Options, Comparison features, and a User list. The website demonstrates a complete full-stack solution using VS Code, Node.js, Bootstrap, CSS, JavaScript, PostgreSQL, Render hosting and a Python-based web crawler.
